# 📅 Kalender Abadi & Hari Besar (2027 - 2100)

Repository ini berisi data lengkap kalender, hari libur nasional Indonesia, serta hari perayaan internasional dari tahun **2027 hingga 2100**.

## 📂 Struktur File
- `calendar-2027-2100.json`: Dataset JSON terstruktur untuk semua hari, hari dalam seminggu, dan daftar perayaan/hari besar dari tahun 2027 sampai 2100.

## 🚀 Penggunaan
Dapat digunakan untuk sistem penjadwalan, aplikasi pengingat, atau riset tanggal di masa depan.
